# ⚡ Weather++ for Minecraft Bedrock Edition

**Weather++** is a Minecraft Bedrock Resource Pack & Companion Studio designed to smooth out rain droplets, eliminate noisy grid textures, and make thunder & lightning cinematic and realistic.

---

## ✨ Features

### 💧 Smooth Rain Droplets
- **Silky Droplet Streaks**: Replaces Minecraft Bedrock's default harsh, opaque pixel lines with anti-aliased, tapered rain streaks with soft alpha falloff and natural droplet spacing.
- **Organic Motion Blur**: Rain streaks stretch naturally with terminal velocity without blocking player visibility.
- **Atmospheric Storm Mist**: Soft ambient mist particles and distance fog smoothing.
- **Enhanced Splash Particles**: Custom concentric water ripple rings and soft micro-splash drops on block collisions.

### ⚡ Cinematic Thunder & Lightning
- **Acoustic Atmospheric Shockwave**: Sharp electrostatic tear & snap on near strikes, followed by authentic rolling thunder echo reverberation.
- **Atmospheric Strobe**: Flash lighting transitions and volumetric storm fog settings.

## 🚀 How to Install into Minecraft Bedrock

### Method 1: 1-Click Import (`.mcpack`)
1. Find `Weather++_Bedrock_Edition.mcpack` in this repository (or download it directly from the web customizer).
2. **Double-click** the file.
3. Minecraft Bedrock will launch automatically and display **"Import Started..."** followed by **"Successfully imported Weather++"**.
4. In Minecraft:
   - Go to **Settings** > **Global Resources** (or your specific World Settings > Resource Packs).
   - Under **My Packs**, click **Weather++** and select **Activate**.

### Method 2: Manual Folder Copy
Copy the `Weather++_Pack` folder to your Bedrock resource pack directory:
- **Windows PC**:
  `%localappdata%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\games\com.mojang\resource_packs\`
- **Android**:
  `/Android/data/com.mojang.minecraftpe/files/games/com.mojang/resource_packs/`
- **iOS**:
  Via iTunes / Files app under `Minecraft > games > com.mojang > resource_packs`

## 🎨 Interactive Companion App & Pack Studio

To launch the real-time simulation and customize your rain / thunder parameters:
1. Open `index.html` in any modern web browser or deploy directly to **Vercel** / **GitHub Pages**.
2. Adjust droplet softness, splash particle multipliers, and storm flash strobe effects in real-time.
3. Click **Export Custom .mcpack** to generate custom Bedrock resource packs!
